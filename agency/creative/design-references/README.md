# Ari UI/UX design-reference snapshots

These are focused, read-only source snapshots retained for reference and provenance. They are **not runtime dependencies** and are not copied into the deployed app. The app uses its own names, copy, CSS, and visual direction rather than cloning any referenced brand or page. Hallmark's snapshot is kept for provenance only; its own guidance discourages applying it to an existing interface unless Hallmark is explicitly requested, so it was not applied. Keep each upstream `LICENSE` with its copied material.

Only focused Markdown and license files are retained here. A pinned UI/UX Pro Max source snapshot was temporarily unpacked to run its read-only local CSV search, then removed; no runtime dependencies or generated design-system files were added. The targeted searches `AI assistant productivity chat interface dark` and `AI chatbot assistant platform` matched AI-Native UI and a chatbot product context. We applied the useful parts—clear conversational hierarchy, one restrained accent, visible keyboard focus, comfortable 48px sign-in controls, responsive layout, reduced-motion support, and honest provider/privacy copy—without copying a palette or framework-specific implementation. A broad generated design-system query returned irrelevant wedding typography and testimonial/landing-page recommendations, so it was rejected rather than persisted. The Instagram Reel itself remains uninspected; its visual details are not represented by these references.
